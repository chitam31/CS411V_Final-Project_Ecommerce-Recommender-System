The architecture has six layers and data flows in one direction. Events come from the replay producer and from the web application, enter Kafka, are stored in the lakehouse, processed by Spark streaming and batch jobs, orchestrated by Airflow, and served by the web application. Everything is containerised, and every script reads the same directory file, so moving a role to another machine is a one-line change — we actually did that for the web host.
