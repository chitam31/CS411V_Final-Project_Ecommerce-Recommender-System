The lakehouse follows the medallion pattern. Bronze keeps raw events exactly as received. Silver cleans them: deduplication by event id and by content, so that a replay never doubles the data, a bot filter, and event weights. Features hold the decayed interaction matrix with append-only indexers, and gold holds everything that is served. Every table except bronze is Delta Lake.
