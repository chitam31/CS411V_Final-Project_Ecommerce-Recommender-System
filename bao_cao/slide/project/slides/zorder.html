The hot query of the web application is the per-user lookup. We measured three phases on a copy of the 5.3-million-row table. Compaction alone barely helps: every compacted file still spans the whole range of user ids. Z-ORDER clusters rows of the same user, narrows each file’s min-max statistics, and lets data skipping read about one file. Files read is the reliable figure; latency varies with Wi-Fi.
